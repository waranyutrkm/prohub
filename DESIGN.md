# ProHub — Obsidian Quant Terminal

Adapted from the visual direction of Global Capital Flow Lab. Dark-first compact research interface.
- Canvas #070a10, cards #0e1524, fields #121a2c, borders #1e2c48.
- Primary #f1f5f9, secondary #94a3b8, cyan #22d3ee, bull #34d399, bear #fb7185.
- Tabular numeric alignment, 13px base, 18px section title, 30px page title.
- 16px section spacing, 10px card radius, minimum 36px controls.
- Use semantic color alongside text; keyboard focus, responsive layout, no decorative emoji.
- Heatmap scores range -100 to +100; missing data must not be colored as neutral.
- Rotation uses absolute Trend and Momentum axes, not relative-return RRG.
- Target WCAG 2.2 AA; independent audit pending.
