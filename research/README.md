# VectorBT exploratory rotation
14 strategy families (12 breadth strategies plus price and hybrid), three rebalance frequencies and three fee assumptions, 126 scenarios plus five benchmarks. Fixed MACD 12/26/9. Shared cash target-percent orders; 0.5% cash buffer; BIL residual. Signal from preceding calendar date, execution at next eligible US-session adjusted close; price momentum 120 sessions lagged one session. No intraday execution simulation, no point-in-time universe. 70/30 chronological exploratory split, not validated OOS. Rank model selects eight; quadrant models select up to three and leave unused slots in BIL. Inverse-vol model uses trailing 20-session volatility; bond and USD proxy scores inverted as a heuristic. Results are generated by Actions, not fabricated. Full parameter optimization, walk-forward and robustness remain future work. Run python -m research.backtest from repository root after installing vectorbt and requirements.
